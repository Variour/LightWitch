# Security Policy

## Supported Versions

This project does not yet have versioned releases. Security fixes are applied to `main`.

## Reporting a Vulnerability

Report vulnerabilities through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/privately-reporting-a-security-vulnerability): open the repository's **Security** tab and select **Report a vulnerability**.

Do not report security vulnerabilities through public GitHub issues.
